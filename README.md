# موقع أبجد لحساب الجمل

الموقع بسيط جدا ل **حساب الجمل** يستخدم **الحروف العربية**  **حسب طريقة حساب السيد أبوأزهر المشايخي حفظه الله**.

## نبذة

حاليا الموقع يقدم حساب الجمل الكبير والمرتبه والصغير سواء رقمي او حرفي او عددي وللمزيد حول طريقة الحساب تفضل بزيارة منتدى الصادق الأمين الروحاني أبو أزهر المشايخي


### مثال لحساب الجمل الكبير

- **أ = 1**
- **ب = 2**
- **ج = 3**
- **د = 4**
- **ه = 5**
- **و = 6**
- **ز = 7**
- **ح = 8**
- **ط = 9**
- **ي = 10**
- **ك = 20**
- الخ...

#### يمكنك تحميل الموقع على جهازك الكمبيوتر او الجوال وفتحه عبر المتصفح كروم أو أي متصفح يناسبك, حيث أنه يعمل بدون توفر خدمة النت.
